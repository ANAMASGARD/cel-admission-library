# Agent Sandbox resource ceilings (C-0303)

SandboxTemplate main containers must specify both limits. Configured maxima apply per resource.

**Admission resources**  `sandboxtemplates`.

**Configuration**  `sandboxCpuLimitMax`, `sandboxMemoryLimitMax`.

**Kubescape severity score**  7.0/10.
