# Minimize the admission of containers wishing to share the host network namespace (C-0196)

Evaluates the Namespace enforce label used by both source rules. Existing workload policies in this family can be bound independently.

**Admission resources**  `namespaces`.

**Kubescape severity score**  5/10.
