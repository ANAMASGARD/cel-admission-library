# Outdated Kubernetes version (C-0273)

Bind with Warn or Audit. The Node status field kubeletVersion describes observed state. Supported kubelet version prefixes follow the pinned Rego revision.

**Admission resources**  `nodes`, `nodes/status`.

**Kubescape severity score**  2.0/10.
