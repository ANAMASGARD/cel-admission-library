# Deprecated Kubernetes image registry (C-0253)

Checks Kubernetes system workload images for the retired k8s.gcr.io registry.

**Admission resources**  `pods`, `pods/ephemeralcontainers`, `deployments`, `replicasets`, `daemonsets`, `statefulsets`, `jobs`, `cronjobs`.

**Kubescape severity score**  5.0/10.
